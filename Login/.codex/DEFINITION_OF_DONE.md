# Definição de Pronto (Codex)

## Objetivo
Padronizar o encerramento de cada tarefa, garantindo que código e documentação estejam sincronizados.

## Checklist de DoD (obrigatório)
- [ ] Código segue MVVM e separação de camadas
- [ ] Sem acesso direto ao banco na UI
- [ ] Regras de segurança mantidas (hash, lockout, auditoria)
- [ ] Docs espelhadas criadas/atualizadas
- [ ] Índices atualizados (`documentos/DOCS_OVERVIEW.md` e `doc_login/INDEX.md`)
- [ ] Como testar descrito (ou testes executados, quando existirem)
- [ ] Links e caminhos revisados

## Evidências mínimas
- [ ] Lista de arquivos alterados apresentada
- [ ] Árvore relevante do repositório apresentada
