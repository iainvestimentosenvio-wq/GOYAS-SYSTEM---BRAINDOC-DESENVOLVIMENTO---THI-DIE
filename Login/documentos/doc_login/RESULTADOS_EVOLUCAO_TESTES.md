Projeto: Performance Optimization - Startup System

## Otimizações Implementadas
### 1. Database Schema Check (Fase 1.2)
- **Arquivo**: `SqliteDb.cs`, `PostgresDb.cs`
- **Mudança**: Adicionar método `SchemaExists()` para verificar se schema já existe antes de executar DDL completo
- **Impacto**: Execuções subsequentes pulam criação de schema (~100-150ms economizados)

### 2. Async File I/O (Fase 1.3)
- **Arquivos**: `AppSettings.cs`, `LocalSettings.cs`
- **Mudança**: Converter `File.ReadAllText()` para `File.ReadAllTextAsync()` e `File.WriteAllText()` para `File.WriteAllTextAsync()`
- **Impacto**: ~20-40ms economizados, evita bloqueio de threads

### 3. Async Patterns (Fase 1.4 & 2.1)
- **Arquivo**: `App.axaml.cs`
- **Mudança**:
  - Converter `BuildStartupServices()` para `BuildStartupServicesAsync()`
  - Converter `MaybeDelay()` (bloqueante com `GetAwaiter().GetResult()`) para `MaybeDelayAsync()` com `await`
  - Adicionar `ConfigureAwait(false)` em todas operações async
- **Impacto**: Eliminar bloqueio de threads, melhor escalabilidade
