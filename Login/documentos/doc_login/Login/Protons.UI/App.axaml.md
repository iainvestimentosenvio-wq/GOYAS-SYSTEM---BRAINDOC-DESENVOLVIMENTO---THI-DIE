# App.axaml

## Objetivo
Definir tema e estilos globais do app Avalonia.

## Como funciona
Carrega o `FluentTheme` e registra o `ViewLocator` para resolver Views a partir dos ViewModels.

## Entradas e saídas
- **Entradas**: nenhuma.
- **Saídas**: estilos globais aplicados na UI.

## Dependências
- Avalonia UI.

## Decisões e porquê
- Tema escuro para aparência moderna e discreta.

## Como testar
- Executar o app e validar que as telas abrem com tema escuro.
