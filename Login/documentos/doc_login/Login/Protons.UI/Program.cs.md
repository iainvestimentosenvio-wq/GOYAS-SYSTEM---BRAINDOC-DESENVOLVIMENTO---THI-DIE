# Program.cs

## Objetivo
Ponto de entrada do aplicativo Avalonia.

## Como funciona
Configura o AppBuilder e inicia o loop de UI.

## Entradas e saídas
- **Entradas**: argumentos de linha de comando.
- **Saídas**: inicialização da aplicação.

## Dependências
- Avalonia.

## Como testar
- Executar `dotnet run` no projeto UI.
