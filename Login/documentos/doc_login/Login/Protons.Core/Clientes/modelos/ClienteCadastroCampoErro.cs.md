# ClienteCadastroCampoErro.cs

## O que este arquivo faz
Define o campo de formulario relacionado ao erro de cadastro de cliente.

## Objetivo
Suportar UX de `banner + destaque de campo` no painel.

## Pontos de atencao
- Usar `Nenhum` para erros tecnicos ou globais.
- Manter alinhamento com os campos reais do formulario.
