# ClienteCadastroErroCodigo.cs

## O que este arquivo faz
Define os codigos estaveis de rejeicao/erro tecnico do cadastro de cliente.

## Objetivo
Permitir que a UI reaja de forma deterministica sem depender de parsing de mensagem textual.

## Pontos de atencao
- Novos codigos devem ser adicionados com cuidado para manter compatibilidade.
- Nao reutilizar codigo existente para outro significado.
