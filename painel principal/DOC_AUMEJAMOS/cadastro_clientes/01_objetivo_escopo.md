# Cadastro de Clientes - Objetivo e Escopo

## Problema de negocio
O cadastro incorreto de cliente aumenta risco de:
- erro humano na operacao;
- falso positivo na vinculacao de tarefas/documentos;
- execucao de tarefa para cliente errado.

## Objetivo
Ter um cadastro confiavel o suficiente para sustentar validacao automatizada de tarefas por cliente.

## Escopo funcional alvo
- Cadastro por CPF/CNPJ.
- Estrutura de grupo empresarial (matriz/filiais).
- Codigo interno do cliente para rastreio operacional.

## Fora de escopo desta fase
- Integracao online em tempo real com API paga oficial.
- Automatizacao sem supervisao em cenarios ambiguos.
