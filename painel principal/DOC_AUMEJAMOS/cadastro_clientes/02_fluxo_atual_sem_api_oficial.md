# Fluxo Atual Sem API Oficial

## Como funciona hoje
1. Operador informa nome, tipo de documento, documento, email e telefone.
2. Dominio valida CPF/CNPJ e impede duplicidade por documento ativo.
3. Cliente e salvo e entra na lista para selecao no painel.

## Campos existentes no cadastro atual
- Nome.
- Tipo do documento (CPF/CNPJ).
- Documento.
- E-mail (opcional).
- Telefone (opcional).

## Limitacoes atuais
- Sem importacao automatica oficial de dados cadastrais.
- Sem estrutura nativa de grupo empresarial.
- Sem codigo interno formal de cliente no modelo atual.

## Regra operacional obrigatoria
Antes de usar automacoes criticas (execucao de tarefas, validacao de documentos e roteamento), a conferenca humana do cadastro deve ser realizada.
