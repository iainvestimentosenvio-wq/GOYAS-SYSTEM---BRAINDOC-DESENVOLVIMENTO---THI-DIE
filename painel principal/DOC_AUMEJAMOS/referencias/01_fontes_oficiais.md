# Fontes Oficiais e Referencias

## Fontes oficiais usadas na estrategia
- API CNPJ oficial (Serpro/Gov): https://www.gov.br/pt-br/servicos/obter-solucao-de-consulta-de-dados-do-cadastro-nacional-de-pessoas-juridicas-cnpj
- API CPF oficial (Serpro/Gov): https://www.gov.br/pt-br/servicos/obter-solucao-de-consulta-de-dados-de-cadastro-de-pessoa-fisica-cpf
- CNPJ alfanumerico (Receita): https://www.gov.br/receitafederal/pt-br/acesso-a-informacao/acoes-e-programas/programas-e-atividades/cnpj-alfanumerico
- Consulta publica CNPJ (manual): https://www.gov.br/pt-br/servicos/consultar-cadastro-nacional-de-pessoas-juridicas
- Dados abertos CNPJ (indice oficial): https://arquivos.receitafederal.gov.br/dados/cnpj/dados_abertos_cnpj/

## Observacoes de custo e contratacao
- Integracao oficial de API (Serpro) depende de contratacao e credenciais da empresa.
- Fluxos gratuitos podem existir para suporte operacional, mas exigem supervisao humana para reduzir risco de erro.

## Distincao operacional
- Fonte oficial paga: maior confiabilidade para validacao automatizada.
- Fonte gratuita assistida: uso tatico com revisao humana obrigatoria.
